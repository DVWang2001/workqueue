🔧 首次設定 Firebase

填好以下步驟後，跨裝置同步就能啟用。

  1. 前往 Firebase Console，建立新專案。
  2. Firestore Database → 建立資料庫 → 選 Production mode。
  3. Authentication → Sign-in method → 啟用 Google。
  4. 專案設定 → 您的應用程式 → 新增網頁應用程式 → 複製 config 物件。
  5. 將 config 貼入 firebase-config.js，取代 YOUR_* 佔位符。
  6. 在 Firestore Rules 頁貼上以下安全性規則後發布：
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{col}/{id} {
      allow read, write: if request.auth.uid == uid;
    }
  }
}

設定完成後重新整理頁面即可使用。
